# 2026-05-03 首页快速导航轻 3D 卡片设计

## 目标
在首页 `src/pages/index.astro` 的“快速导航”区域引入轻量 3D 卡片效果，参考 Uiverse 组件的分层与透视思路，但保持当前博客的蓝色、玻璃感、现代科技风格，不影响 `/blog` 页和全局 `Card.astro`。

## 范围
- 仅修改首页快速导航卡片
- 不修改博客列表卡片
- 不修改全局布局与其他页面组件

## 设计原则
1. 与现有视觉系统兼容：沿用 `var(--c-primary)`、玻璃感、圆角、柔和阴影
2. 动效克制：避免强烈翻转，保持轻 3D
3. 分层明确：图标、标题、描述、装饰层存在轻微 Z 轴层次
4. 渐进增强：移动端和减少动画偏好场景自动降级

## 方案
### 卡片结构
保留现有 `.nav-card` 为基础，增加轻量的 3D 包装层与装饰层：
- 外层：负责 `perspective`
- 卡片主体：负责背景、边框、hover 倾斜
- 内容层：图标、标题、描述、hover 光效
- 装饰层：轻几何纹理/高光，不使用过强棋盘背景

### 视觉样式
- 背景：蓝白透明渐变 + 很淡的几何纹理
- 边框：半透明亮边
- 阴影：默认柔和，hover 时增强
- 高光：hover 时有轻微扫光/背景位移
- 重点卡片：前两个导航卡片层次略强，其他卡片稍弱

### 交互行为
- 默认：卡片保持静止，具有层次感
- hover：
  - 卡片轻微 `rotateX/rotateY`
  - 整体微抬升
  - 内容 `translateZ`
  - 背景纹理轻位移
  - 阴影增强
- 游戏卡片：保留 dropdown，统一视觉语言，避免过强旋转影响可用性

### 降级策略
- `@media (max-width: 768px)`：关闭明显 3D 倾斜，仅保留阴影/位移
- `prefers-reduced-motion: reduce`：关闭主要 3D 动效和纹理位移

## 实现方式
优先仅编辑 `src/pages/index.astro`：
- 必要时对快速导航卡片 HTML 结构做局部调整
- 样式集中写在该页面内，避免影响其他页面
- 如需脚本，仅限该页面内联、最小化处理

## 验收标准
1. 首页快速导航卡片呈现轻 3D 视觉效果
2. 风格与当前首页兼容，不显得突兀
3. 游戏 dropdown 正常工作
4. 移动端无明显布局错乱
5. 深色模式下仍协调可读
